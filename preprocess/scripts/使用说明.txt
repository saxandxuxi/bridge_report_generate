============================================================
桥数据预处理 - 项目使用说明
============================================================

一、三个文件夹的用途
------------------------------------------------------------
1. 处理脚本\   存放所有处理数据的脚本(预处理、图库、对照表生成等)
2. 图库\       存放各传感器各特征的统计图
   - <传感器编号>\<特征>\时间序列图.png   每日均值/最大/最小曲线
   - <传感器编号>\<特征>\频率分布图.png   小时均值分布直方图
   - <传感器编号>\相关性_<特征A>_<特征B>.png  特征间相关性散点图(可选)
3. 统计值\     存放查询用的统计值 JSON(全部中文键)
   - 传感器编号名称.json   编号 -> 中文监测部位对照(由 docx 生成)
   - <传感器编号>.json     每个传感器的分特征统计 + 每日统计
   - 总览.json             全部传感器的总览

二、处理流程
------------------------------------------------------------
第 1 步: 原始数据预处理(按天聚合为小时统计)
    python 处理脚本\run_preprocess_all_sensors.py
    输出: D:\preprocess_sensor_data\daily\<传感器>\<特征>\<日期>.csv
    说明: summary.csv 会在结束后自动按 传感器/特征/日期 排序去重;
          断点续跑跳过的任务也会回填汇总记录，不再丢失。

第 2 步: 生成图库 + 统计值
    python 处理脚本\build_chart_library.py
    默认读取 D:\preprocess_sensor_data\daily,
    输出到 D:\preprocess_sensor_data\图库 和 D:\preprocess_sensor_data\统计值

    常用参数:
      --correlation     同时生成特征间相关性分析图(默认关闭)
      --limit-sensors N 只处理前 N 个传感器(试跑)
      --start/--end     只统计指定日期范围
      --daily-root/--lib-root  覆盖输入输出路径
      --rebuild-summary 先从 daily 目录重新生成 summary.csv，再生成图库
                        (不重跑预处理，适合 daily 已有、汇总表丢失/不全时)

    第 2.5 步: 生成季度统计值(小时级，同监测部位多传感器取均值)
    python 处理脚本\build_quarterly_stats.py
        --daily-root D:\preprocess_sensor_data\daily
        --lib-root   D:\preprocess_sensor_data
    输出: 统计值\季度统计.json

    统计前统一清洗(与绘图同一套逻辑):
      - 物理合理范围过滤: 湿度 0~100%、温度 -80~80℃、风速 0~100 m/s、
        索力 0~10 万 KN、位移/挠度 ±10 万 mm、应变 ±5 万 με 等，
        超出范围的值(如采集错误码 435000、9e7)一律用稳健基线替代并记录
      - 零散尖峰替代 + 规律性高峰保护(见上文)
      - 同一监测部位同一特征有多个传感器时，按小时取各传感器均值，
        最大值取各传感器最大、最小值取最小

    图库生成失败/数据不足时会记录到: 图库\生成失败记录.txt

    进一步预处理(默认开启，生成统计值和图之前执行):
      - 数据按小时级加载(daily 每天 24 行)，时间序列图一天描 24 个点，
        横轴仍标日期；只有没有 daily 时才回退 summary.csv(日级)
      - 零散尖峰点(均值/最大/最小三个序列各自检测): 用去掉上下 5%
        极端值后的稳健基线判定，偏离超过 --spike-threshold 倍MAD、
        且连续不超过 3 小时的点才是尖峰候选；每个序列最多替代
        --max-spikes(默认3)个最极端的，其余视为正常分布尾部不替代；
        风类特征(spfs/szfs 长尾分布、spfx/szfx 圆形量)不做尖峰判定，
        只做范围过滤(真实大风/阵风不被误删)；
        替代记录写入 JSON 的 "预处理.尖峰替代"，图上 黑x=统计尖峰、
        红x=物理范围外剔除；同一小时在多天重复出现的"规律性高峰"
        (如早晚高峰)视为常态不替代
      - 数据缺失(连续 >= --gap-fill-hours 小时，默认24): 在图上橙色
        标注缺失区间("数据缺失 Nh: x月x日x时~x月x日x时 (已线性填充)")，
        绘图序列用首尾有效值线性插值填充；统计值仍按真实数据计算，
        缺失区间写入 JSON 的 "预处理.数据缺失填充"
      - 长时间突变段: 当天"偏高/偏低小时"占比 >= 60%、且连续
        >= --shift-min-days 天(默认 7)才判定为突变区间；在时间序列图上
        着色并标注 "x月x日x时~x月x日x时 均值xx 偏高/偏低"(精确到小时)，
        区间详情写入 JSON 的 "预处理.突变区间"
      参数: --spike-threshold 5.0(默认) / --gap-fill-hours 24(0=关闭) /
            --max-spikes 3 / --shift-threshold 2.5 / --shift-min-days 7；
            流量/计数类特征(如人流量)建议 --spike-threshold 0 关闭尖峰替代

第 3 步(一次性): 生成传感器编号对照表(完善版)
    python 处理脚本\parse_sensor_map.py [docx路径] [输出json路径]
    已生成:
      - 统计值\传感器编号名称.json(1157 个传感器, 含特征编码)
      - 统计值\传感器名称对照\<桥名>.json(每桥一个, 完善版):
          * 传感器名称 -> [{编号, 特征, 位置, 方向, 特征编码, 测点}]
          * 测点映射: 结构应变/振动监测表 断面位置 -> 测点N -> 编号
          * 表格映射: 梁端支座位移/墩顶支座倾角/裂缝/温湿度/结构温度 表
    特征编码来自 Q1 统计值(自动读取 统计值\ 目录)，
    先跑完预处理和图库统计再执行本脚本，映射最准确。

第 4 步(可选): 单独修复/重建 summary.csv(不重跑预处理)
    python 处理脚本\build_summary_from_daily.py
        --daily-root D:\preprocess_sensor_data\daily
        --summary    D:\preprocess_sensor_data\summary.csv
    直接从 daily 目录重新汇总，按 传感器/特征/日期 排序输出。

三、统计值 JSON 里的中文键
------------------------------------------------------------
平均值 / 中位数 / 标准差 / 最大值 / 最小值 / 差值 /
最大值_实测 / 最小值_实测 / 绝对最大值 / 均方根值 /
有效小时数 / 缺失小时数 / 覆盖天数 / 每日统计(日期,平均值,最大值,最小值)

四、参考脚本说明
------------------------------------------------------------
本项目已把 D:\五座桥数据分析文件 中旧脚本的目标统计量和图
(时间序列图、频率直方图、相关性密度散点图+回归线,
 平均值/最大/最小/差值/绝对最大/均方根/缺失) 集成到
build_chart_library.py，旧的分散脚本不再需要逐桥维护。
